Reconfigure an R&D lab without rebuilding it

Modular benches that change with each project.

Industrial System
Request this setupAll solutions

The problem

Every new project needs a different layout. The team spends days moving fixed benches, rerouting cables and clearing clutter before the actual work can start.

Why it happens

Fixed benches are built for one layout. Storage and power are tied to the bench position.

How the setup comes together

  1. Start with Flexi starter units for each work zone.
  2. Add adder or corner units as the team or project grows.
  3. Mount power and instruments on the uprighter so they move with the bench.
  4. Keep prototypes and samples in mobile cabinets assigned to each project.

What changes

The lab changes layout in hours rather than days, and instruments, power and storage move with the work.

The setup

  • Flexi SystemSingle and double-sided starter and adder units in inline, back-to-back or C layouts
  • Scitec Series workbenchTechnical benches, available on castors
  • Link uprighter, shelves and overhead cabinetsPower rail, instrument shelves and cable management on the bench
  • Mobile cabinetStorage that moves with the project

All standard modules. Sizes, worktops and colours are chosen for your space.

Where it applies

ManufacturingAerospace & aviationOil & gasHealthcare

Standards it supports

ISO 9001; IEC 61340-5-1 where electronics are handled.
