Product catalogues.

Two catalogues cover the full Furnisys range. Start with the pre-configured catalogue for proven, ready-to-order setups, or use the configurable catalogue to build a system around a critical application. Catalogues are shared on request.

2026–27

Pre-configured catalogue

Setups that buyers have used again and again, packaged as ready-to-order products. Choosing a pre-configured product saves time in configuring and delivering the solution, shortening the overall project cycle.

  • Base, Pro and Scitec workbenches
  • Link uprighters, workstands, trolleys and flow racks
  • Flexi workstations, universal carts and flow racks
  • Base and mobile cabinets
  • Lean workspace and ergonomics guidance
Request the pre-configured catalogue
2026–27

Configurable catalogue

Every pre-engineered module, accessory and option, so a system can be configured for applications where the function is critical, without the risk of one-off fabrication.

  • All worktop, leg and accessory options
  • Above and below worksurface accessories
  • Shallow and full depth cabinet ranges
  • Pegboard, rail, shelf and lighting options
  • Full configuration features for every system
Request the configurable catalogue

How to read a part number.

Pre-configured products are ordered by part number. Each part number is built from the product, the worksurface, the size and the colour.

PRWB-0110ProductPLWWorksurface723072" long × 30" deepBEBlue

Example from the catalogue: a PRWB-0110 Pro workbench with a 72" postform laminated worksurface in blue is ordered as PRWB-0110-PLW-7230-BE.

Worksurface codes

PLWPostform laminated particle board
PELWPostform electrostatic (ESD) laminated particle board
HPLHigh pressure laminate
GWGI sheet over plyboard
SSWStainless steel sheet over plyboard
